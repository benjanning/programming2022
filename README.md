# Ben Janning
### Data Analytics · Python · SQL · Web Applications

I build practical tools that turn data and requirements into something people can use. My background combines a **Higher Diploma in Computing (Data Analytics)** at Atlantic Technological University with hands-on Python, statistical analysis, databases, APIs and web development.

This page is a guide to my selected projects. Each repository includes source code and, where available, the research, visualisations and technical decisions behind the work.
